# deObAI releases

Binary release artifacts for deObAI. The source lives in a private repository.

Download the latest Linux desktop builds from the Releases page, and verify the
SHA-256 checksums published with each release.

The binaries are distributed under the MIT license; see [LICENSE](LICENSE).
See [VERIFY.md](VERIFY.md) for checksum, Sigstore signature, and third-party
notice information.

Windows, macOS, and Android packages are not published yet.
